# Графический эквалайзер

Реализация 10-полосного графического эквалайзера на пиковых БИХ-фильтрах 2-го порядка для FPGA-платы **Terasic DE1-SoC**. Звук принимается с аудиокодека платы по I²S, обрабатывается каскадом цифровых фильтров в логике FPGA и отправляется обратно на кодек.

## Возможности

- 10 частотных полос: 31.5 Гц, 63 Гц, 125 Гц, 250 Гц, 500 Гц, 1 кГц, 2 кГц, 4 кГц, 8 кГц, 16 кГц
- Стерео: левый и правый каналы обрабатываются параллельно двумя независимыми цепочками фильтров
- Каждая полоса включается и выключается отдельным переключателем `SW`
- 24-битные аудиоотсчёты, коэффициенты фильтров в формате с фиксированной точкой (32 бит со знаком)
- Кнопка mute и аппаратный сброс
- Светодиоды показывают, какие полосы сейчас включены

Фильтры включены последовательно (каскад). Если полоса выключена (`enable = 0`), её фильтр сбрасывает внутреннее состояние и пропускает сигнал без изменений.

## Управление

| Элемент платы | Назначение |
|---------------|------------|
| `SW[9]` | Полоса 31.5 Гц |
| `SW[8]` | Полоса 63 Гц |
| `SW[7]` | Полоса 125 Гц |
| `SW[6]` | Полоса 250 Гц |
| `SW[5]` | Полоса 500 Гц |
| `SW[4]` | Полоса 1 кГц |
| `SW[3]` | Полоса 2 кГц |
| `SW[2]` | Полоса 4 кГц |
| `SW[1]` | Полоса 8 кГц |
| `SW[0]` | Полоса 16 кГц |
| `KEY[0]`, `KEY[1]` | Перезапуск конфигурации кодека (модуль `keytr`) |
| `KEY[1]` | Удерживать для отключения звука (mute) |
| `KEY[2]` | Сброс аудио-PLL |
| `KEY[3]` | Сброс эквалайзера и I²S-модулей |
| `LEDR[9:0]` | Отображают состояние `SW[9:0]` |

## Структура репозитория

| Путь | Описание |
|------|----------|
| `DE1_SoC_i2sound.v` | Верхний модуль проекта: конфигурация кодека, I²S, каскад БИХ-фильтров |
| `DE1_SoC_i2sound.qpf` | Файл проекта Quartus |
| `DE1_SoC_i2sound.qsf` | Назначение выводов и настройки проекта |
| `AudioPLL/` | Аудио-PLL, формирует тактовый сигнал `AUD_XCK` (MCLK) для кодека |
| `v/` | Verilog-модули проекта |
